System Monitor

Gadget เล็กๆ ลอยมุมขวาล่างของจอ แสดง CPU / RAM / Disk / เน็ต, usage ของ Claude Code และปฏิทินตั้งโต๊ะ สำหรับ Windows ติดตั้งด้วยคำสั่งบรรทัดเดียว A tiny always-on-top gadget for Windows showing CPU / RAM / Disk / Network, Claude Code usage and a desk calendar. Installs with one line.

ติดตั้งInstall

  1. กดปุ่ม Windows พิมพ์ cmd แล้วกด EnterPress the Windows key, type cmd and press Enter.
  2. กดปุ่ม Copy ด้านล่าง แล้ววางในหน้าต่างนั้น (คลิกขวา) และกด EnterPress Copy below, paste it into that window (right-click) and press Enter.
  3. จะมีคำถามว่าจะแสดง usage ของ Claude Code ไหม ถ้าไม่ได้ใช้ Claude Code พิมพ์ n หรือกด EnterIt asks whether to show Claude Code usage. If you don't use Claude Code, type n or just press Enter.
  4. รอสักครู่ gadget จะขึ้นที่มุมขวาล่างเองWait a moment; the gadget appears at the bottom right.

      Latest version: v1.3.1 · Windows 10 / 11 · no admin rights · nothing else to install

ควรรู้ก่อนติดตั้งBefore you install

    
    
      
  • คำสั่งนี้ดาวน์โหลดสคริปต์จาก GitHub แล้วรันทันที โค้ดทั้งหมดเป็นข้อความธรรมดา เปิดอ่านก่อนได้ที่ GitHubThis command downloads a script from GitHub and runs it right away. All code is plain text; read it first on GitHub.
    • 
      
  • ถ้าตอบ y ในคำถาม Claude จะมีการเพิ่ม statusLine ใน ~\.claude\settings.json (สำรองไฟล์เดิมไว้ให้)If you answer y to the Claude question, a statusLine entry is added to ~\.claude\settings.json (your original is backed up).
    • 
      
  • ตัวเลือก "Live Claude usage" (ปิดไว้เป็นค่าเริ่มต้น): ถ้าติ๊กเอง โปรแกรมจะอ่าน token ล็อกอินของ Claude Code แบบอ่านอย่างเดียว แล้วถาม api.anthropic.com ทุก 2 นาที (endpoint ไม่เป็นทางการ)Optional "Live Claude usage" (off by default): if you tick it, the gadget reads your Claude Code login token (read-only) and asks api.anthropic.com every 2 minutes (unofficial endpoint).
    • 
      
  • ใช้ Ollama Cloud ด้วย? เปิด Settings แล้ววาง API key จาก ollama.com/settings/keys ในส่วน Ollama Cloud กด Connect จะเห็น usage ของ Ollama Cloud ใน gadget (คีย์เก็บแบบเข้ารหัส และส่งไปที่ ollama.com เท่านั้น)Using Ollama Cloud? Open Settings, paste an API key from ollama.com/settings/keys in the Ollama Cloud section and press Connect to see your Ollama Cloud usage in the gadget (the key is stored encrypted and only sent to ollama.com).
    • 
      
  • ใช้ OpenRouter หรือ DeepSeek? ใส่ API key ในแท็บของแต่ละเจ้าใน Settings ได้เหมือน Ollama: OpenRouter แสดงยอดใช้ของคีย์ (และวงเงินถ้าตั้งไว้) ส่วน DeepSeek แสดงยอดเงินคงเหลือUsing OpenRouter or DeepSeek? Add an API key in its Settings tab the same way: OpenRouter shows the key's spend (and its limit, if set), DeepSeek shows your remaining balance.
    • 
      
  • ใช้ Codex CLI? gadget จะแสดง usage 5hr / Week ของ Codex เองโดยอ่านจากไฟล์ session ในเครื่อง (ไม่ส่งข้อมูลออกไป)Using the Codex CLI? The gadget shows its 5hr / Week usage automatically, read from Codex's session files on your PC (nothing is sent anywhere).
    • 
      
  • โปรแกรมเช็กเวอร์ชันใหม่วันละครั้ง (เรียก api.github.com เท่านั้น) และติดตั้งให้เอง ปิดได้ที่ Settings (เฟือง ⚙ มุมขวาบน)The gadget checks for a new version daily (only contacts api.github.com) and installs it by itself. Turn it off in Settings (the ⚙ at the top right).
    • 
    

    

      Windows Defender / Antivirus บางตัวอาจเตือน เพราะโปรแกรมรันแบบซ่อนหน้าต่างดำ (สคริปต์ที่ไม่ได้เซ็นชื่อ) ถ้าไม่สบายใจ ไม่ต้องติดตั้งก็ได้
      Windows Defender / antivirus may warn because the program runs with a hidden console window (unsigned script). If you're not comfortable, don't install it.

รันคำสั่งนี้ใน cmd จะลบโปรแกรม ค่าตั้งค่า และรายการเปิดพร้อม WindowsRun this in cmd. It removes the program, its settings and the startup entry.
